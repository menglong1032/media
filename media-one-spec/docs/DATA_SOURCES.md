# MEDIA ONE｜数据源与字段分工

版本：V1.0

## 总原则

不存在单一“最权威、最完整”的影视网站。MEDIA ONE 按字段选择最合适来源，并保留所有来源值与溯源信息。

外部网站是 Source / Evidence，MEDIA ONE 自有数据库是最终主库。

---

## 1905电影网

定位：**中文影片与影人资料核心来源之一。**

重点字段：

- 中文片名与影片基础资料
- 完整演职员
- 演员角色
- 制作机构
- 发行机构
- 上映地区与日期
- 奖项
- 海报 / 剧照
- 视频
- 影人简介
- 影人作品履历
- 人物评价
- 合作关系
- 星路历程 / 人物经历

特别规则：

- 1905 的星路历程优先作为中文人物时间轴骨架。
- 1905 作品表不视为绝对完整，必须与其他来源做并集。
- 基础事实存在冲突时保留原始值，并由其他来源交叉验证。

---

## 豆瓣

定位：**中文用户语境下的重要影视元数据与辅助匹配源。**

重点：

- 中文片名
- 别名
- 简介
- 评分
- 演职员
- 角色与作品关系补充
- 影片图片
- 人物作品履历辅助

已有方案统一称为：**豆瓣元素刮削**。

---

## TMDb

定位：**全球作品统一身份、国际图片与季集结构的重要基础源。**

重点：

- TMDb Work / Person ID
- 原名
- 国际片名
- Person movie credits
- Cast / Crew
- 电视剧季集结构
- Poster
- Backdrop
- Logo
- 多语言图片

TMDb 适合承担自动漏片检测的重要来源之一。

---

## IMDb

定位：**国际专业演职员 Credits 与作品身份补充。**

重点：

- IMDb Title ID
- IMDb Name ID
- Cast / Crew
- 更细的专业工种 Credits
- 国际作品关系

注意：IMDb 可接受社区贡献，因此重要事实仍应保留来源并交叉验证。

---

## 猫眼

定位：**中国院线、市场热度、影人作品和宣发资料的重要补充源。**

重点：

- 影人作品
- 角色
- 中国院线作品
- 票房
- 想看 / 热度
- 视频与宣发素材
- 上映信息

注意猫眼“作品数量”可能混合电影、电视剧、综艺、真人秀、晚会和出镜等，必须重新分类。

---

## 淘票票 / 灯塔

定位：**中国院线与市场数据补充。**

重点：

- 票房
- 排片
- 热度
- 想看
- 市场趋势
- 影片宣发数据

---

## IMP Awards

定位：**高质量、多版本海报专用源。**

重点：

- 高清主海报
- Alternate Poster
- Character Poster
- International Poster
- 不同地区版本
- 不同设计版本

主要解决“有图但分辨率过低”的问题。

---

## 6huo

定位：**预告片发现、视频分类与来源索引层。**

重点：

- Teaser
- Trailer
- Final Trailer
- IMAX Trailer
- Featurette
- Clip
- MV
- BTS
- 宣发素材
- 发布日期
- 时长
- 上游视频来源

6huo 主要用于“发现”和“辨别视频类型”，再追踪原始平台确认官方性。

---

## Mtime 时光网

定位：**影片、人物、视频、影视资讯、片单和内容关联补充源。**

重点：

- 影片资料
- 人物资料
- 预告片
- 视频
- 新闻
- 片单
- 宣发内容

部分 6huo 视频可回溯至 Mtime 视频体系。

---

## Wikidata

定位：**跨数据库 ID 映射辅助。**

重点：

- 人物实体对齐
- 作品实体对齐
- IMDb 等外部 ID 映射
- 多语言名称辅助

不承担所有影视内容的主数据来源职责。

---

## 官方来源

包括但不限于：

- 影片官方账号
- 制片公司
- 发行公司
- 演员工作室 / 经纪公司
- 奖项官方页面
- 国家级或行业权威机构

对于明确的官方事实，官方来源拥有较高 SOURCE AUTHORITY。

# 字段级优先思路

## 中文人物经历

1905 → 官方 / 权威媒体 → 猫眼 / Mtime / 豆瓣补充

## 完整电影作品表

1905 + TMDb + IMDb + 豆瓣 + 猫眼 + Mtime 做并集，再统一验证。

## 角色名

1905 / 官方 → 豆瓣 / 猫眼 → IMDb / TMDb 交叉验证。

## 完整演职员

1905 + IMDb → TMDb / 豆瓣补充。

## 海报

IMP Awards + TMDb → 1905 / 豆瓣 / 猫眼补充中文宣发图。

## 剧照

1905 / 豆瓣 / TMDb / 猫眼交叉补充。

## 预告片

6huo 负责发现与分类 → Mtime / 猫眼 / 影片官方平台确认上游与官方性。

## 奖项

奖项官方 → 1905 → IMDb / 其他可靠来源。

## 中国票房与热度

灯塔 / 猫眼 / 淘票票等市场来源交叉使用。

# 数据冲突处理

每个字段不要只保存一个最终值。

建议至少保存：

- source
- source_item_id
- raw_value
- normalized_value
- preferred_value
- confidence
- verification_status
- last_checked
- manual_lock

原则：

1. 来源值不互相覆盖。
2. 选择主值与保存原始值是两回事。
3. 人工确认后可锁定。
4. 权威官方来源可以高于普通聚合来源。
5. 多来源一致可提高可信度，但来源数量不是唯一判断依据。
