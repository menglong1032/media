# MEDIA ONE Spec

MEDIA ONE 的长期项目总纲与规范仓库目录。

本目录用于长期保存并持续更新影视系统的产品架构、数据源优先级、影人资料体系、资源自动整理流程、刮削规范与版本变更记录。

## 核心目标

MEDIA ONE 不是单一播放器或流媒体皮肤，而是一个面向私人媒体库的影视知识与资源管理系统，最终覆盖：

- 影视资料数据库
- 多源元数据融合
- 影人知识库与人物经历时间轴
- 海报 / 剧照 / 预告片资产管理
- 私人媒体库与网盘资源整理
- 按影人自动整理作品
- 推荐与发现
- 播放器
- 与直播 / 音乐 / 图库的跨模块关联

## 长期原则

1. 外部网站只是 Source，不是最终数据库。
2. 自己的 WORK、PERSON、关系、媒体资源和来源记录必须长期稳定。
3. 多源采集、统一身份、字段级融合、数据溯源、人工可锁定。
4. 1905 是中文影片与影人资料的核心来源之一，尤其重视星路历程、完整演职员、角色、奖项与机构信息。
5. 任何单一来源都可能遗漏或出错，最终以多源交叉验证与自有数据库为准。

> 后续所有已经确定的重要规则，应优先更新到本目录，而不是只散落在聊天记录中。
